月次トレンドレポート 2026-10

前月からの変化

  • エージェントの権限境界とサンドボックスは、ツール個別の既定値から「基盤の境界問題」へ広がった。Claude の auto モードが web／デスクトップ／モバイルでも既定になり、CNCF は「エージェントはツールが許すことしかできない」としてプラットフォーム設計の話に引き上げた。
  • 複数エージェントの並行実行は製品に組み込まれた（Claude Code Projects、dynamic workflows、Orca、Band）一方で、増やしすぎへの反省が出た。Anthropic の single-agent-loop-kit と「12 体を文脈で切り直す」実践が、いつ単一ループに畳むかを論点にした。
  • 計算資源の無駄削減は、クラスタの requests/limits からモデルのルーティングとトークン効率へ重心が移った。Haiku 5.5 の値下げ、Copilot Fusion、Junie Eco Mode、TokenEconomizer が同じ月に出ている。
  • AGENTS.md による指示ファイルの共通化は、共通化の利点より「実行される入力」としての危険が前面に出た。ダウンロードフォルダの AGENTS.md 経由の乗っ取りと、Cursor マーケットで配布された改ざん版 Claude Code 拡張が同じ月に報告された。
  • AI 時代のコードレビューは議論から運用へ移り、Anthropic の 7 層レビュー、Code Review の GA、ReviewBench、AI レビューだけで 83% をマージした事例が揃った。
  • Platform Engineering 2.0 は「Agent-first IDP（AEP）」として具体化し、Block／Uber／AWS／Azure／Google の 9 実践と AgentCore のリファレンス構成が出た。
