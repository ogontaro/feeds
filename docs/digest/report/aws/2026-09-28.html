Strands Agentsに「Strands harness」が追加されました！

AWS のエージェント SDK「Strands Agents」に、新しく「Strands harness」が追加された。従来の SDK と何が違うのかを実際に触って確かめた内容で、Bedrock を前提にエージェントを組んでいるなら、どちらを使うかの判断材料になる。新機能の追加は実装の選択肢が増える変更なので、追っておく価値がある。
