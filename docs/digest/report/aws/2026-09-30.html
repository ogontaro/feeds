OpenAI を搭載した Amazon Bedrock Managed Agents がプレビュー開始

AWS と OpenAI が共同開発した Bedrock ネイティブのエージェント基盤で、すでに使っている ID・権限・ガバナンスをそのまま流用し、AWS 内だけで動く OpenAI モデル上のエージェントを組める。状態の保持、ツールの選択と実行、コード実行、複数ステップにわたる作業の調整までを基盤側が引き受けるため、エージェントの権限境界や実行の隔離を自前で作り込むべきかどうかの判断材料になる。エージェントを基盤の利用者として扱う構成を考えるうえで、プレビューの段階で触っておく価値がある。

コンデナストが Amazon Bedrock でマルチモーダル動画検索を構築
