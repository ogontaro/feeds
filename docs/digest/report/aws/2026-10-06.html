GLM 5.3(Z.ai)が Amazon Bedrock で一般提供開始

AWS Batch が Amazon EKS のアクセスエントリ認証に対応

Batch のコンピュート環境が、aws-auth ConfigMap ではなく EKS アクセスエントリ経由でクラスタに認証できるようになった。IAM プリンシパルへの権限付与を API 駆動で管理できるので、クラスタ認証のライフサイクル管理が単純化する。EKS のアクセスエントリへ移行中の環境では、Batch が移行の足枷にならないことをここで確認しておきたい。

SageMaker の推論最適化スキル「aws-ai-ml」がコーディングエージェント向けに公開
