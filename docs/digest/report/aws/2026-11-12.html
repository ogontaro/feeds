Amazon EKS Auto Mode が Pod 単位のセキュリティグループに対応

Auto Mode のノードでも Pod ごとに EC2 セキュリティグループを割り当てられるようになり、アプリごとにノードプールを分けずにネットワークを分離できる。RDS や ElastiCache への到達範囲を Pod 単位で絞れるので、マルチテナントや本番・検証が混在するクラスタの設計にそのまま効く。Terraform で EKS を管理しているなら、ノードプール分割の前提を見直すきっかけになる。
