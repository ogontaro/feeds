Amazon Bedrock AgentCore Identity のディスカバリー URL が OAuth 2.0 の認可サーバーメタデータに対応

AgentCore Identity のディスカバリー機能が RFC 8414(OAuth 2.0 認可サーバーメタデータ)に対応した。外部 IdP をエージェントの認証に組み込むとき、認可・トークンのエンドポイントをメタデータから自動で取得できるため、手書きの設定を減らせる。MCP サーバーや社内 SaaS にエージェントを繋ぐ構成を組むなら、認証まわりの実装がどう変わるか確認しておきたい。

Amazon Bedrock AgentCore Identity がプライベート認証局(CA)に対応

AgentCore Identity がプライベート CA の証明書を扱えるようになった。自前 PKI で発行した証明書を使う閉域寄りのエージェント構成でも、AWS 側のマネージドな ID 基盤をそのまま使える。社内 CA の運用ルールがある組織ほど効いてくる変更で、前段の OAuth メタデータ対応と合わせてエージェント認証の土台が固まってきている。
