EKS のサービスロールに VPC の DHCP オプションを読む権限が追加

AmazonEKSServiceRolePolicy に ec2:DescribeDhcpOptions が追加され、コントロールプレーンがクラスタ VPC の DHCP オプションセットから DNS サーバーとドメイン名を読めるようになりました。クラスタの IAM ロールにこの権限が無くても VPC 側の設定に追従し、DHCP オプションセットを差し替えれば新しい設定が自動で使われます。カスタム DHCP オプションを使う VPC では、コントロールプレーンの DNS 解決の前提が変わりうるので確認しておきたい変更です。
