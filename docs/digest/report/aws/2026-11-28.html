Amazon Neptune Graph Sessions が登場、アイドル時にゼロへスケールするエージェント向けグラフ

GraphRAG や AI エージェントのように「ユーザー・タスクごとに 1 つのグラフ」を持たせたい用途を狙った、アイドル時にメモリと CPU をゼロへ落とすコンピュートモードが GA になった。プロビジョンドグラフの 16 m-NCU 最低課金を避けて 4 s-NCU(セッション容量単位)から始められるため、多数のエージェントを並行して動かす構成のコスト設計が変わる。エージェントごとにナレッジグラフを分ける設計を検討しているなら、費用対効果の見積もり直しに効く。

CloudWatch が AWS サービスメトリクスの OpenTelemetry 基本エンリッチメントを追加コストなしで提供

AWS サービスが CloudWatch に出すメトリクスを、PromQL で引ける OpenTelemetry のデータポイントへ変換する機能が無料で使えるようになった。ARN・クラウドプロバイダー・リージョン・アカウント ID といったリソース属性が付くので、CloudWatch 側のメトリクスを OTel ベースの可観測性スタックへ寄せるときに、変換層を自前で作り込む手間が減る。メトリクス基盤を OpenTelemetry に統一しつつあるなら、取り込み経路の見直し材料になる。
