Bedrock の OpenAI モデルでも reasoning summaries が使えるようになったので試してみた

Amazon Bedrock 上の OpenAI モデルで reasoning summaries(推論過程の要約)が取得できるようになり、curl と AWS CLI で実際に動作を確認した記事です。推論モデルをエージェントやバッチ処理に組み込むとき、モデルが何を根拠にその結論を出したかを後から追えるかどうかは、出力の検証やプロンプト改善のしやすさに直結します。Bedrock 経由で複数ベンダーのモデルを同じインターフェースから呼ぶ構成では、推論トレースの扱いがモデルごとに揃っていくのかが実務上の分岐点になるため、手元で挙動を確かめておく価値があります。
