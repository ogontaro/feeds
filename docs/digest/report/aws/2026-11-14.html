AWS Batch on EKS が Linux capabilities・seccomp・Pod 単位の設定に対応

EKS のジョブ定義で Kubernetes の securityContext を細かく指定できるようになり、Linux capabilities、seccomp プロファイル、Pod 単位の設定を扱える。Pod Security Standards の restricted プロファイルを強制しているクラスタでも、ジョブに必要な権限とシステムコールだけを与えて Batch を動かせる。restricted 運用を緩めずにバッチ基盤を同居させたいときの制約が 1 つ外れる。

Bedrock AgentCore Identity が OAuth 2.0 の discovery URL に対応

これまで AgentCore Identity は OIDC の discovery URL しか受け付けず、OIDC を使わない OAuth 2.0 認可サーバーはメタデータの公開パスが違うため設定できなかった。今回、受信側の JWT 認可と送信側の OAuth 資格情報プロバイダの両方で OAuth 2.0 の discovery URL を指定できる。社内 IdP が OIDC 非対応でも、エージェントに資格情報を持たせず認可サーバーへ委ねる構成を組める。
