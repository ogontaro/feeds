IAM ロールの背後にいるユーザー／ワークロードの ID を引き継ぐ trusted identity propagation

AWS のリクエストごとに、IAM ロールを引き受けたユーザーまたはワークロード（アプリケーションや自動化フローなどの非人間の呼び出し元）の ID を引き継ぎ、認可と監査をその ID 単位で行えるようにする仕組みです。エージェントや自動化ワークロードが同じロールを共有する構成では、ロール単位の監査ログだけでは「誰がやったか」が追えません。権限設計と監査の粒度を見直すきっかけになります。
