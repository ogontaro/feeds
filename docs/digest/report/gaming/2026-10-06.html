Steam Frame 向け SteamOS 0.4.4 ベータ、プレゼンスセンサー感度の設定が追加

Steam Frame のベータチャンネル向けに SteamOS 0.4.4 が配信された。装着検知（プレゼンスセンサー）の感度をユーザーが選べる設定が入り、眼鏡スペーサーを使う場合など幅広い条件でもディスプレイが点灯し続ける「高感度」オプションが加わっている。発売前のベータ段階で装着まわりの使い勝手が詰められていることがうかがえ、Steam Frame の購入判断や、ベータチャンネルに参加するかどうかの材料になる。

Moonlight PC v6.2.0 が正式リリース

自宅ゲームストリーミングのクライアント側を担う Moonlight の新しい正式版（nightly や prerelease ではない）が出た。配布物は Windows（インストーラー / ポータブル x64・ARM64）、macOS、Linux の Snap・Flatpak・AppImage、Raspberry Pi 向け、汎用 ARM 32/64bit Debian、実験的な RISC-V Debian、NVIDIA Jetson と Nintendo Switch（Ubuntu L4T）、Steam Link と幅広い。ホスト側に Sunshine や Apollo を立てて自宅環境を組んでいるなら、クライアントを更新するタイミングとして確認しておきたい。
