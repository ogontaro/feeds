OpenNOW 1.0.3 正式リリース、複数アカウント切り替えとプラン別 DLSS 表示が入る

GeForce NOW を自前クライアントで扱う OpenNOW の 1.0.3 が正式リリースになった。複数アカウントを同時にサインインさせて起動時に選ぶ機能、NVIDIA の DLSS 対応リストに基づくラベル表示とプラン(メンバーシップ)別の DLSS 対応・上書き、左ドックに移った Ctrl+G ドロワーとクイックトグル、ゲームタイルの情報量増加が入っている。nightly を追いかけなくても実用的な変更がまとまって入る区切りなので、GeForce NOW を自前クライアントで使っているなら更新判断の材料になる。

OpenNOW の Decky プラグイン 0.1.0 公開、Steam のゲームモードから直接使えるように

OpenNOW を Decky Loader 経由で入れるプラグインが 0.1.0 として公開された。Decky の Developer タブから URL を指定してインストールする形で、Steam のゲームモードから OpenNOW を扱えるようにするもの。ゲームモードに統合されるかどうかは Steam Deck をストリーミング端末として使うときの手数に直結するので、デスクトップモードへ切り替える手間を減らしたい人には効く。
