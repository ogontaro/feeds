Claude Code の守りのフックは、壊れると黙って通る — 2.1.295 の onFailure: 「block」

Claude Code のフックは、コマンドが起動できないなど「そもそも動かない」場合に処理を止めず、黙って通してしまう挙動だったという指摘。2.1.295（2026-10-08）で追加された onFailure: 「block」を使うと、command フックと HTTP フックが起動できないときに止められる。危険なコマンドを拒否する守りのフックを置いているなら、守っているつもりで素通りしている箇所がないか確かめる価値がある。
