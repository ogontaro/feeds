Claude Code v2.1.277: CLAUDE.md が無ければ AGENTS.md を読むように

CLAUDE.md を持たないプロジェクトでは、Claude Code が代わりに AGENTS.md を読み込むようになりました。Codex など他のコーディングエージェントと指示ファイルを共有していたり、AGENTS.md を正として運用しているチームにとっては、既存の資産がそのまま効くようになる変更です。読み込ませる内容は /config の「Project instructions」から確認・差し替えできます(Bedrock、Vertex、Foundry ではまだ利用不可)。 原文を読む

Claude Code v2.1.278: auto mode の分類器がサーバー側デフォルトに(課金の前提が変わる)

auto mode の分類器が、Claude API / Enterprise および Bedrock・Vertex・Foundry・ゲートウェイ経由でデフォルトでサーバー側実行になりました。分類器のオーバーヘッドには課金されないため、auto mode を常用しているチームはコスト見積もりの前提が変わります。課金対象へのフォールバック時には警告が出るほか、/status の Auto mode server 行で自分のセッションがどちらで動いているか分かるので、まずそこを確認しておくのが確実です。 原文を読む

Claude Code v2.1.277 の信頼性修正 — claude -p のハング、Grep/Glob の誤報告など

ヘッドレス実行や Agent SDK を CI・自動化に組み込んでいる人に効く修正がまとまっています。内部エラー後に claude -p や SDK のセッションが結果を返さず無言でハングしていたのが、エラーを報告して終了コード 1 で終わるようになり、Grep/Glob も資源不足で検索を開始できなかったときに「一致なし」と偽らずエラーを返すようになりました。どちらも「失敗を成功と誤認する」種類の不具合で、パイプラインの信頼性に直結します。Write や Edit のエラー処理、古いビルドにログアウトさせられる問題なども直っています。 原文を読む
