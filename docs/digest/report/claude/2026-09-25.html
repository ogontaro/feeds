Claude Code v2.1.282: セッション再開や作業中のコマンドで拡張思考が失われる問題の修正

--continue / --resume での再開や、作業中に /model・/rename などの即時実行コマンドを使ったときに、それまでの拡張思考が破棄されてしまう問題がまとめて直りました。長時間セッションや再開を前提にした運用では推論の文脈が静かに落ちる分だけ出力品質が下がるため、症状が分かりにくいタイプの不具合です。要約リクエストが拒否されてコンパクションが失敗したときにフォールバックモデルで再試行する修正も入り、セッションが途中で死ににくくなっています。 原文を読む

Claude Code v2.1.282: 権限ルールと設定ロックの効き方を修正 — 統制の穴を塞ぐ

パターン途中に :* を含む Bash 権限ルールが設定ファイルでは無視され、--allowedTools でしか効いていなかった問題が修正され、全ソースで機能するようになりました(マッチ方法を説明する起動時の警告も追加)。あわせて真偽値のロックキーに誤った型を書いても無視されないようになり、macOS のシンボリックリンク経由で意図しない CLAUDE.md や rules が読み込まれる問題も塞がっています。権限・統制の設定が「書いたつもりで効いていない」状態は事故に直結するので、managed settings を配っているチームほど挙動を確認しておく価値があります。 原文を読む
