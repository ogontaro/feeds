Claude Code に消させたファイルは /rewind では戻らないことがある

Claude が変えたファイルを戻す /rewind が、どこまで戻せるのかをダミーファイル 5 通りの変更 × 15 回で実測した記事。削除されたファイルは戻らず、メニューに「No code changes」と出るかどうかが見分け方になるという。復元できる前提で破壊的な操作を任せる前に、守備範囲を正確に知っておきたい。

Claude Code v2.1.300 / v2.1.301 — オートモードの判断根拠が OpenTelemetry で見えるようになった

v2.1.300 で OpenTelemetry の GenAI 属性が追加され、Claude Platform on AWS の /advisor にも対応した。続く v2.1.301 では tool_decision イベントに classifier_verdict・permission_mode・classifier_category が加わり、自動承認が分類器の判断によるものか権限ルールによるものかを区別して追えるようになっている。エージェントにどこまで権限を渡すかを運用で詰めるとき、判断の内訳を後から検証できるのは大きい。同じリリースでは、未プッシュのコミットを残したまま WorktreeCreate フックのワークツリーを確認なしに削除してしまう問題も修正された。
