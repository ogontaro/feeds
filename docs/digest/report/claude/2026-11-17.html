新ツール・サブスク（1 本）

JS レンダリング後のページを読める Web fetch を Claude Code / Cursor に与える「webfetch.run」

コーディングエージェント内蔵の fetch は静的ページには強くても、JavaScript で描画されるページや cookie バナー、後から書き込まれる検索結果には弱い。webfetch.run はその穴を埋めるホステッド MCP サーバーで、エージェントが「ページが空」と答える場面が多いなら試す価値がある。
