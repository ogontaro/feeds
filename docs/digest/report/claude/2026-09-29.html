Claude Sonnet 5.5 の登場と Opus 5.5 との使い分け

opencode の欠陥で、悪意のある Web サイトから開発者マシンでのコード実行が可能に

コーディングエージェント opencode の欠陥により、悪意のある Web サイトが開発者のマシンでコードを実行できるようになる、という指摘です。コーディングエージェントはローカルのシェルとファイルへの広い権限を持つため、利用しているツールの更新状況を確認するきっかけになります。
