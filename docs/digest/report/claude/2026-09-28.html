AIデバッグはなぜ収束しないのか — P2がいつまでも消えない理由

Claude Code の Effort はタスクごとに切り替える — 常に Max ではいけない理由

Claude Code の Effort（思考量）を常に High/Max で回すのではなく、タスクごとに切り替えるべきだという整理。Effort を上げると単純に「賢くなる」のではなく、自分で検証したりテストしたり別解を試したりする量が増えるという指摘が要点で、Low=アイデア出し・ラフ作成・軽微な修正、Medium=通常の開発・新機能実装、High=バグ修正・レビュー・検証、Max=難しい問題をほぼ自律的に最後まで解かせる、という対応づけが示されている。仕様をClaudeにインタビューさせる→Low/Mediumで実装→人間が確認→Highで検証、という流れも含め、待ち時間と利用量に直結する日々の使い方の判断材料になる。

whiteboard — 図からコードへ辿れる、設計意図の可視化ツール
