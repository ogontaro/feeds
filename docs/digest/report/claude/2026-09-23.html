Claude Code v2.1.280 — 実務に効く修正(シンボリックリンク書き込みの判定と auto mode の再試行)

シンボリックリンク経由の書き込みを、作業ツリー内のパス表記ではなく実際の着地点で判定するようになり、承認プロンプトには着地点が表示され、acceptEdits / allow ルール / auto モードは作業ツリー外に着地する書き込みを承認しなくなった。安全側に倒れた重要な変更なので、共有リポジトリで自動承認を使っているなら挙動の変化を把握しておきたい。あわせて、safety check が拒否したアクションを auto mode が繰り返し再試行する問題(リトライはバックオフし、連続 10 回でターン停止)、MCP のツール説明・サーバー指示文に効く 2,048 文字上限を変える CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH、Write 呼び出しの引数名ゆれの許容、モデル切替やフォークサブエージェント再開時のプロンプトキャッシュ破損の修正も入っている。MCP サーバーを自作している人ほど上限緩和が効く。 原文を読む
