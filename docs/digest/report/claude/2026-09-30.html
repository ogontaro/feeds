OpenAI DevDay 2026: 常時稼働エージェント「dots」と Codex のクラウド実行環境

OpenAI が DevDay で、独自のクラウド計算機を持ち 24 時間動き続けるエージェント「dots」を発表した。接続したアプリのバグ報告や機能要望の整理から、Codex でビルド・テストして PR を返すところまで任せられ、Pro プランに含まれ使用量も消費しない。あわせて Codex のクラウド実行環境と CLI の刷新も出ており、コーディングエージェントの主戦場が手元のターミナルから「クラウドで常時動く」側へ移りつつあることが分かる。

OpenAI、月額 500 ドルの Pro プランを開始し 200 ドルプランの使用枠を半減

コーディングエージェントのサブスクは「いくらで何がどれだけ使えるか」が争点になっており、OpenAI は 500 ドルの Pro を新設する一方、200 ドルプランは実質の使用枠が半分になった。同じ 200 ドルでも Claude Max は月およそ 9,000 ドル相当の Opus 使用量に匹敵するという計測が共有されており、料金表の数字だけでは判断できないことが分かる。ChatGPT のサブスク枠を Devin など他社ツールで使えるようにする動きも始まっており、枠の持ち込み合戦が次の論点になりそうだ。
