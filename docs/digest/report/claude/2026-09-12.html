シンボリックリンク越しのパスで permission の deny/confirm ルールが効いていなかった不具合を修正（Claude Code v2.1.268）

macOS の /etc・/tmp・/var、Linux の /bin のようにシンボリックリンクになっているディレクトリでは、deny ルールを実体パスで書いても、あるいはシンボリックリンクのパス表記で書いても、Bash コマンドから見ると適用されないケースがあった。意図したサンドボックス制限が実は抜け穴になっていたという話なので、権限設定でパスベースの deny/confirm ルールを運用している人は要チェック。 原文を読む / Google 翻訳で全文を読む

WebFetch が応答を開いたまま完了しないサーバーで無期限にハングする不具合を修正、300秒タイムアウトと環境変数での上書きに対応（Claude Code v2.1.268）

これまで WebFetch はサーバーがレスポンスを開始したまま完了させない場合に永久に待ち続けることがあったが、300秒で自動的に失敗するようになり、CLAUDE_CODE_WEBFETCH_DEADLINE_MS で時間を変更（0 で無効化）できるようになった。フックやワークフローで WebFetch を組み込んでいると地味に刺さる不具合だったので、自動化を組んでいる人には実務的に効く修正。 原文を読む / Google 翻訳で全文を読む
