URL パーサーの解釈差が Kyverno の namespace 分離を破った事例

Kyverno による namespace 分離が、URL の解釈差（パーサー・ダイバーシファル）を突かれて破られたという Akamai の研究。マルチテナントの境界をポリシーエンジンに委ねる構成では、同じ入力がコンポーネントごとに違う意味へ解釈されると防御そのものが成立しない、という設計側の問題として読める。Kyverno を使っていなくても、ポリシーでテナント境界を作る設計全般に効く話なので、隔離の前提をどこに置いているかを点検する材料になる。

AI エージェントに SSH 鍵を渡さない——委任 ID でインフラの権限を絞る

開発者が AI エージェントに「Kubernetes の Pod が落ちる理由を調べさせると、エージェントにはログを読む権限が要る」という場面から、エージェントへ恒久的な鍵や広い権限を渡す危険を扱う記事。Teleport の委任 ID（delegated identity）による解決を軸に、人間の権限を短命に引き継がせる設計を論じている。エージェントを基盤の利用者に含めるなら認証・認可の境界をどう引くかが論点になり、手元のクラスタでエージェントに kubectl を渡す場面が増えている今、権限の粒度を決める参考になる。
