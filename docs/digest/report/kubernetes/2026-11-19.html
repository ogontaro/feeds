nginx に未認証 RCE「NGINX2Shell」、HTTP/2 を使う 1.31.8 が対象

現行 mainline の nginx 1.31.8 に、認証なしでリモートからコード実行が可能な HTTP/2 の脆弱性が見つかり、CVE-2026-123007 を筆頭に計5件の脆弱性がまとめて報告されている。Ingress やリバースプロキシとして nginx を前段に置く Kubernetes 構成は影響範囲が広く、公開直後に国の注意喚起も出ている。HTTP/2 応答と Server: nginx ヘッダーの組み合わせで対象を絞り込めるので、まず自クラスタの ingress を洗っておきたい。
