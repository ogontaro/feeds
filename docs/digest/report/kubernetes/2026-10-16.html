OpenTelemetry に「カーボン」を第一級シグナルとして載せる設計

CNCF ブログで、Software Carbon Intensity(SCI)をログ・メトリクス・トレースと同格のシグナルとして OpenTelemetry に組み込む設計が共有された。収集を OTel に寄せている構成では、消費電力や炭素排出は今のところ独自メトリクスでしか拾えず、標準化されれば既存のダッシュボードやアラートの対象にそのまま乗る。リソース要求の適正化をコスト削減だけでなく環境負荷の指標としても説明できるようになる、という点が実務に効く。

kubernetes-sigs の Cluster Inventory API が v0.2.0

複数クラスタの情報を 1 つの API で扱う kubernetes-sigs の Cluster Inventory API が v0.2.0 になった。ClusterProfile と PlacementDecision の v1alpha2 API が入り、CRD の検証や kubectl の表示、クラスタへのアクセス設定も改善している。「どのワークロードをどのクラスタに置くか」を宣言的に決めるための土台になる部品で、α のうちから動きを追っておくと後で構成を組むときに効く。
