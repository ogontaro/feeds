OpenTelemetry Collector の File Log レシーバー、チェックポイントを protobuf 化して保存・読み込みが約5倍高速に

Collector Contrib v0.164.0 から、File Log レシーバーが storage extension に書くチェックポイントが常に protobuf 形式になった。ベンチマークでは保存が約5倍、読み込みが5倍以上速くなったと報告されている。ログ収集エージェントを各ノードで動かしている構成では、ポーリングのたびに走るこの書き込みが地味な負荷になるため、Collector のバージョンを上げる際に確認しておきたい変更だ。
