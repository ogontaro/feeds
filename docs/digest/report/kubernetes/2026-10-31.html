OpenTelemetry eBPF Instrumentation が v1.0.0 に到達

Kubernetes に workload conformance グループが発足

Kubernetes にワークロードの準拠(conformance)を扱うグループが発足した。これまで主に API やノードのレベルで語られてきた準拠の対象がワークロードの挙動まで広がると、AI 推論のような独自ワークロードを載せるときの移植性や、実装間の比較軸に影響してくる。AI チーム向けの意味づけも含めて、推論基盤を設計する際の前提を確認しておきたい。

GPU が忙しくても AI 推論は遅い — Kubernetes 上の推論を可観測性で捉える

クラスタが健全に見えても、その上の AI 推論サービスがユーザーを失望させていることがある、という問題提起。GPU の稼働率が高いことは推論が速いことを意味せず、待ち行列や応答時間など別の指標を見ないと遅さは見えてこない。GPU 利用率を主要な健全性シグナルにしているなら、SLO とアラートの設計を見直すきっかけになる。
