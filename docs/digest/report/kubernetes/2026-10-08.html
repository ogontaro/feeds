Harbor の Webhook に SSRF——任意のユーザーがサーバーのクラウド資格情報に到達できる

CNCF のコンテナレジストリ Harbor の Webhook に SSRF があり、任意のユーザーがサーバーのクラウド資格情報に到達できてしまうという OX Security の調査。レジストリは全クラスタのイメージ取得元であり、Webhook のように「外へリクエストを出す」機能はメタデータエンドポイントや内部 API への足がかりになりやすい。Harbor を自前で運用していなくても、外向きリクエストを許すコンポーネントの権限と到達範囲を見直す材料として効く。
