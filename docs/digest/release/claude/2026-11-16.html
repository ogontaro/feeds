Claude Code v2.1.321–v2.1.325

破壊的変更: なし。ただし v2.1.321 で Fable 5.2（claude-fable-5-2、1M コンテキスト、$8/$40 per Mtok・キャッシュ読み出し $0.20）が既定の Fable モデルになり、モデル ID と単価が変わる。v2.1.323 からは plugin.json の engines["claude-code"] 範囲外のプラグインがインストール・更新・読み込みの対象外になる。
実験的な Code Mode（Claude がツール呼び出しを JavaScript で書く）がオプトインで追加され、組織単位で無効化もできる。プラグイン側が対応バージョン範囲を宣言できるようになり、ハーネス（権限・ツール・指示の外側の構成）を配布物として管理する流れが進んだ。
権限境界まわりの修正が多く、MCP OAuth のリダイレクトで refresh token が別ホストへ送られる問題、読み取り専用 Bash がプロンプトなしにサンドボックス外で走る問題、cp/mv 先ディレクトリへの deny ルールが効かない問題を修正。サブエージェントが独自モデル時に main セッションのモデルでファイル読み取りサイズを見積もる問題も直り、並行実行の精度が上がっている。
ほかに Vertex（global/us/eu）の fast mode 対応、第三者ゲートウェイ・Foundry で毎ターン context length エラーになる問題の修正、zstd 圧縮レスポンスのデコードに関するセキュリティ修正を含む。

opencode v2.2.7–v2.3.0

破壊的変更: v2.2.7 で @opencode/ai の ImageResponse.image が削除（response.images[0] へ移行）。プラグイン読み込みを待たない SDK エンドポイントが増え、*.updated イベントで再取得する前提になった。v2.3.0 でサブエージェントは常にバックグラウンド実行・即時返却に変わり、TUI の transcript 既定が low（ツール呼び出しと思考を1行に集約）になる。
v2.3.0 の目玉はサブエージェントのバックグラウンド化で、複数を並行に走らせながら親セッションで作業を続けられる。アイドル時に親へ報告し、子のバックグラウンド処理が残っている場合は「まだ実行中」と伝えて部分結果を完了扱いしない。
MCP イベントの実験的対応、shell コマンドのサーバーハンドオフ越しの継続、mTLS 用クライアント証明書、ローカルモデル探索（Ollama / LM Studio / vLLM）のタイムアウト延長なども入った。MCP OAuth の refresh token ローテーションで複数クライアントが同時更新してもログアウトしない修正は、MCP を常用する環境で効く。
Codex と同様に Code Mode の構造化結果が整理され、ファイル・skill ツールの戻り値が単純化された。process-daemon v0.5.1 / v0.5.2 はビルドと依存更新のみ。

Orca 1.4.255–1.4.259 / Android 0.0.65

破壊的変更: Android アプリが新アプリ dev.orca.app に移行した。旧 com.stably.orca.mobile は今回が最終更新で、セキュリティ修正を含め今後一切更新されない。新アプリは別パッケージなので上書き更新できず、一度インストールして再ペアリングする必要がある。
1.4.259 で Workspace Cleanup がオプトインで追加された。ルールは既定でオフだが、有効化すると削除プレビュー確認後に条件一致のワークスペースが数秒で消えるため、プロジェクト単位のルールを設定する前にプレビューを確認したい。
機能面ではサブエージェントを1体ずつ専用ビューで追えるようになり、Kimi Code を Chat から利用可能。1.4.258 で GitHub Copilot Chat、1.4.257 でブラウザの未送信フィードバックの復元と音声入力の無音待ち設定、1.4.255 で Session History 検索の高速化とスマホの Agents タブが入った。
1.4.256 の音声入力はオンデバイスモデルの再ダウンロードが必要になる場合がある。スマホ側の改善は対応するアプリ更新が前提。

Codex CLI 0.169.0

破壊的変更: codex exec / codex review は信頼していないディレクトリで、--sandbox workspace-write を付けてもプロジェクト設定と MCP サーバーを無効のまま維持するようになった。プロジェクトを信頼するには --trust の明示が必要。
0.169.0 ではオプトインのターミナルワークスペースが複数のサイドチャットタブに対応し、再起動後もローカルのサイドチャットを復元する。過去タスクを名前・プロンプト・作業ディレクトリで検索でき、フルスクリーン表示では完了した作業を折りたためる。
カスタムモデルプロバイダーを TUI から追加・編集でき、SSH 越しやブラウザなしでもデバイスコードでゲートウェイ認証できる。macOS / Linux のオプトイン Cloud 接続では画像送信・モデル選択・会話のアーカイブがターミナルから可能。Ctrl+S でアップロード無効時も診断 ZIP をローカル保存できる。
0.170.0 / 0.171.0 の alpha はリリースノート未記載のため、バグ修正と依存更新のみ。
