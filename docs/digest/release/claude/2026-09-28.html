Claude Code v2.1.280〜v2.1.283

破壊的変更: v2.1.280 で Claude Opus 5.5(claude-opus-5-5)が既定の Opus モデルになった(1M コンテキスト、$4/$20 per Mtok、キャッシュ読み $0.20/Mtok)。モデルやコストを固定している環境は要確認。同じ版でダイアログのキー操作が変わり、y/n での確認・取消が廃止されて Enter/Esc に統一(y/n を戻すには keybindings.json に confirm:yes/confirm:no を割り当てる)。Ctrl+C / Ctrl+D の2回押しでダイアログごと終了しなくなった点も従来と逆。v2.1.283 は claude plugin validate が厳格化し、インストールできないプラグイン／マーケットプレイス名や、プラグイン ディレクトリ外を指す outputStyles/themes/monitors/lspServers が検証エラーになるため、プラグイン配布側の CI は通らなくなる可能性がある。v2.1.282 では settings の Bash 権限ルール(time -p make build のような中間 :* パターン)が全ソースで有効になり、managed settings の真偽値ロックは打ち間違えても適用されるようになった(起動時にキー名を表示)。いずれも移行作業は不要だが、プラグイン検証とモデル既定値は影響が出やすい。

  • 新機能: maxProseWidth(広いターミナルで本文だけ幅を制限)、fullscreen のマウス操作拡充(/skills などのスクロール、項目クリック)、/feedback のスクロールバー、他セッションの切り詰めメッセージのクリック展開、CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH(MCP 説明文の 2,048 字上限を変更)。管理・ゲートウェイ向けに availableModelsMatch: "exact" と deniedModels、gateway の x-claude-code-prompt-id(CLAUDE_CODE_GATEWAY_HINT_HEADERS=1)、OTel の tool.output イベント(MCP/WebFetch/WebSearch、OTEL_LOG_TOOL_CONTENT=1)、Bedrock upstream の assume_role と guardrail、load_test_mode、Mantle upstream が追加された。
  • このリポジトリに関係する点: v2.1.281 の "attribution": false は commit/PR の帰属表示を消せるが、このキーを含む settings ファイルは古い CLI が丸ごと読み飛ばすため、バージョン混在のファイルには入れない(CI とローカルを同じ settings.json で運用している場合は注意)。v2.1.283 の /doctor prompt-audit(/checkup prompt-audit)は CLAUDE.md・スキル・エージェント・コマンドを「旧モデル向けに書かれたプロンプト」の観点で監査するので、本リポジトリの CLAUDE.md / report-criteria の見直しに使える。
  • 主な修正: ロングセッションの信頼性が中心。継続・再開時に過去のメッセージが変わった形で再送され、API が以前の推論(extended thinking)を捨てる問題、プロキシ／ゲートウェイがストリームを切った応答を「完了」と表示する／重複イベントでツールが二重実行される問題、Content block not found で部分応答が失われる問題、redacted_thinking で毎ターン失敗する問題(thinking を捨てて1回再試行)、--max-turns を無視した無限再試行、再試行中の "unrecoverable interface error" クラッシュ、compaction 失敗時のフォールバック再試行、MCP 再接続中にプロンプトキャッシュが失われる問題を修正。auto モードが安全チェックの拒否・無応答で延々リトライする問題、シンボリックリンク経由の書き込みが auto モード / acceptEdits で承認されてしまう問題、壊れた installed_plugins.json でプラグインが消える／復元される問題も直っている。MCP は 2026-07-28 接続での URL モード elicitation に対応し、claude plugin validate が .mcp.json の無効エントリも報告するようになった。
