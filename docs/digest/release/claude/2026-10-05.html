Claude Code releases v2.1.284〜v2.1.289

破壊的変更: Sonnet の既定モデルが Sonnet 5.5(claude-sonnet-5-5、1M context・$2/$10 per Mtok・キャッシュ読み $0.20/Mtok)に変わりました。v2.1.287 の MCP URL プロンプト対応(2025-11-25 プロトコル)以降サーバーに接続できなくなった場合は、その MCP 設定に "bareElicitationCapability": true を追加してください。v2.1.288 の VS Code 向け claude auth status 変更はサインアウトが増える恐れがあり、v2.1.289 で差し戻されています。

今週の目玉は Claude Mods(プラグインがより深い挙動まで変更できるようになった)と、組み込み mod「You should know」(別のエージェントが作業の抜けを監視して指摘。/plugin enable cc-plugin-you-should-know@builtin で有効化、テレメトリ有効なファーストパーティセッション向け)です。
権限境界・サンドボックスの修正が集中しており、sandbox auto-allow 下で環境変数展開付きコマンド(TZ="$HOME" rm -rf build)や変数代入付きコマンドが deny/ask ルールをすり抜ける問題、複合シェルコマンドの deny/ask が mod の承認に上書きされる問題、シンボリックリンク経由で Read deny を回避できる問題、ユーザー製プラグインが組織管理 MCP のサインインツール説明を書き換えられる問題を修正しました。エージェントの権限境界とサンドボックスを常用する立場では、優先して取り込みたい内容です。
信頼性面では、応答途中の API タイムアウトを部分応答から継続、compaction 後も「Prompt is too long」が続く問題、--resume が直前のコンテキストや最後の応答を落とす問題を修正。fork サブエージェントが親の権限モードを継承するようになり、agent.spawn や .agent.list() の idle/waiting が加わって、複数エージェントの並行実行と協調が扱いやすくなりました。
そのほか、/code-review --max-findings、agents view の名前検索(Ctrl+F)とグループ移動、claude --desktop、allowedProviders による provider 制限、CLAUDE_CODE_DISABLE_WEB_FETCH、claude plugin configure、ゲートウェイの Google Cloud OTLP テレメトリ転送と spend 金額表示が入っています。
