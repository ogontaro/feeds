今週のリリース

Claude Code v2.1.311〜v2.1.316

破壊的変更: Opus 4.8 の fast モードは 2026-10-30 に非推奨、11-30 に削除される。以降 Opus 4.8 への fast リクエストはエラーになり標準モードへフォールバックしないため、速度を維持するには Opus 5.5 への移行が必要。加えて Bedrock / Vertex / Foundry / Mantle で未知のモデル名(カスタムデプロイ名など)を使う場合、Sonnet / Haiku 相当でも短いシステムプロンプトに切り替わる(CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 で従来動作)。フックは1セッション最大24並列(タイムアウト待ちは別枠12)に制限された。
権限境界の強化として、全パーミッションモードで作業ディレクトリ外への Write / Edit / NotebookEdit を拒否する permissions.blockWritesOutsideWorkingDirectories が追加され、--restricted での外部ファイルアップロードの抜けも修正された。サブエージェントは CLAUDE_CODE_SUBAGENT_EFFORT で既定の effort を指定でき、親サブエージェントのモデル継承がバックグラウンド復帰時に崩れる不具合も直り、並行実行の挙動を揃えやすくなった。
Claude apps gateway にはグループで1つの月次予算を共有する pooled_budget、複数ポリシーを重ねる managed.policy_mode: layered、Bedrock guardrail 用の guardrail.input_tagging、Entra ID の oid などで識別する oidc.user_id_claim が入り、組織の統制とコスト管理が厚くなった。VS Code / Claude Desktop にはアイドル時の自動圧縮(200K トークン超)も追加されている。
安定性では、終了時にシェルコマンドが残る問題、SHELLOPTS 設定時に bash スクリプトが1コマンドで止まる問題、PreCompact フックの巨大出力で圧縮が失敗する問題(出力は10,000文字で打ち切り)、圧縮レスポンス切断時のリクエストハング、クロス署名ルート証明書による TLS エラーなどを修正。CLAUDE_CODE_DISABLE_ULTRATHINK も追加された。
