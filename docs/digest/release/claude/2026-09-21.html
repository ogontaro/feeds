Claude Code v2.1.271〜v2.1.278

破壊的変更: v2.1.278 で auto モードの分類器がサーバーサイド既定に変更（Claude API / Enterprise、および Bedrock / Vertex / Foundry / 各種ゲートウェイ）。分類器自体のオーバーヘッドは課金されないが、課金対象のフォールバックに切り替わると警告が出るため、コスト管理上は要確認。Bedrock / Vertex / Foundry / ゲートウェイでは CLAUDE_CODE_AUTO_MODE_SERVER=0 でオプトアウト可能（課金ドキュメント）。また v2.1.273 は 2.1.268 の「権限チェッカーが解析できない Bash 行に Read/Edit の拒否ルールを適用する」変更をリバートし、time -p make build のようなコマンドが再び確認プロンプト対象に戻る。加えて v2.1.275 で発生したプロキシ／ゲートウェイ環境の全リクエスト 400 エラー（advisor_20260301）は v2.1.276 で修正済みのため、該当環境は 2.1.276 以降へ更新が必要。

  • 新機能: CLAUDE.md が無いプロジェクトで AGENTS.md を読む対応（Bedrock / Vertex / Foundry は未対応）、claude.ai アカウントで有効化したスキル・プラグインの端末セッションへの同期、送信キー（ctrl+enter / ctrl+x ctrl+s）によるキュー中メッセージの一括送信、Remote セッション（クラウド／セルフホストランナー）での fast モード、/config のマウス操作、auto モード＋サンドボックスでの per-command allowed_domains、サブエージェントの omitClaudeMd。
  • ゲートウェイ／エンタープライズ: ゲートウェイ サインイン時のアカウント確認と /status 表示、upstream への静的 headers 指定、egress が転送プロキシのみの構成向け CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1、LLM ゲートウェイ向けリクエストヘッダ（CLAUDE_CODE_GATEWAY_HINT_HEADERS=1）、claude_code.llm_request スパンへの effort 属性や managed-settings 解決イベントなど OTel の拡充。
  • 主な修正: クラッシュ・ハング系が多数修正（~/.claude.json の不正値による起動クラッシュ、壊れたトランスクリプトでの --resume 失敗、メモリ逼迫時の Read ハング、Edit が \uXXXX を誤解釈する問題、Grep/Glob がリソース枯渇時に「該当なし」と誤報告する問題、MCP のタイムアウト／再接続失敗）。v2.1.272 は「バグ修正と信頼性向上」のみの内容。
