Claude Code v2.1.317〜v2.1.319

破壊的変更: auto モードの判定が変わる。テレメトリやフィーチャーフラグが無効な場合、および LLM ゲートウェイ経由の場合、サーバーが確認できない呼び出しは確認プロンプトか拒否になり、内蔵分類器へのフォールバックがなくなる。従来動作は CLAUDE_CODE_AUTO_MODE_SERVER=0、ゲートウェイで CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS を使う場合は CLAUDE_CODE_AUTO_MODE_SERVER=1 も必要（Bedrock/Vertex/Foundry は不変）。また claude -p がディスク不足やクォータでトランスクリプトを失ったときの終了コードが 0 から 1 になった。
MCP サーバーがツール呼び出しをタスクとして実行したとき、即座にバックグラウンドへ移して完了時に Claude へ結果を返す「MCP タスク」に対応した（CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND で従来どおり待機）。MCP を常用していると、長時間のツール呼び出しでターンが止まらなくなる。
permissions.denyInsteadOfPrompting を追加し、許可プロンプト待ちになる呼び出しを拒否してターンを継続できる。サブエージェントやチームにも効くため、権限境界の設計にそのまま使える。/tasks には「Earlier in this session」行が加わり、終了したサブエージェントを開き直してメッセージを送れる。
ゲートウェイ運用向けに /usage の日・週・月支出、管理 API のコストレポート（GET /v1/organizations/analytics/cost）、pooled 予算の優先順位、assume_role、JSON ログを追加。OTel には anthropic.plan / seat_type / provider などが加わった。Web/シェルツールがアカウントのメールアドレスを外部へ送る前の確認、--continue の回帰修正、旧ハンドシェイクの MCP 接続失敗の修正なども含む。

opencode v2.2.6（+ @opencode/pty 0.5.0）

破壊的変更: opencode run が、プロンプトが起動したバックグラウンドのシェルコマンド・サブエージェント・画像ジョブの完了を待つようになり、待ち時間に上限がない。dev サーバーのように終わらないジョブがあると Ctrl+C / SIGTERM まで run が開いたままなので、CI では必ずタイムアウトを設定する。SIGTERM はセッションとバックグラウンドジョブをキャンセルして終了コード 143 で終わる。
pool: true による MCP 接続の共有を追加し、同じ構成のプロジェクト間で 1 接続を使い回してプロセス数と起動時間を減らせる。opencode run -w（--worktree=<name>）で git worktree 内からセッションを開始でき、--archived を付けるとスクリプトや CI のセッションをインボックスとセッション一覧から外せる。
セキュリティ面の変更が多い。ファイル読み出しとメディアはサンドボックス化したダウンロードとして配信し、/api/* へのクロスサイト遷移と許可外オリジンからのリクエストを拒否。webfetch は資格情報を含む URL を拒否し #fragment を権限照合から除外、Code Mode の fetch は全リダイレクトを webfetch ルールと照合する。session_move がプロジェクト外へ出る前に external_directory 権限を要求する。
ほかに Code Mode の実験的バイトコード VM（既定オフ）、プロバイダ/モデル別のセッションウォーム（interval: "auto" はキャッシュ TTL 基準）、GUI プラグインのテーマとスロット、Foundry 上の Claude モデル向け Azure Messages 対応。別パッケージ @opencode/pty 0.5.0（protocol 8）も公開された。

Codex CLI 0.167.0（0.167〜0.169 の alpha を含む）

破壊的変更: なし。0.167.0 が安定版で、0.168.0 / 0.169.0 系の alpha はノートが「Release 0.169.0-alpha.N」のみのため中身は不明。
codex agents --no-daemon でエージェントのコマンドセンターを開けるようになり、未読の結果がマークされる。ターミナルのセッションピッカーから接続中のバックエンドを切り替えても下書きが保持される。
権限まわりでは、[permissions.network] の管理されたコマンドチェックポイントが毎回の人間承認を要求し、Guardian が記録済みの exec 呼び出しを直接レビューする。MCP の共有接続にはチャット単位のリースが付いた。
Google Cloud Vertex AI のセットアップウィザード（ADC または資格情報ファイル）、/experimental からの macOS/Windows システムプロキシ有効化、ローカル画像添付のプレビューに対応。Ctrl+L で表示だけをクリアして Ctrl+T で履歴を残す変更や、失敗応答を考慮した自動コンパクションの修正も入る。

Orca v1.4.247〜v1.4.254（+ Android 0.0.63/0.0.64）

破壊的変更: v1.4.252 で macOS 13.4 以上が必須になった（従来は 12）。v1.4.251 でネストした worker の既定深さが 1 から 4 に変わり、既存プロファイルも 4 へ移行する（設定で戻せる）。Chat UI のメニューから「Fork Agent Session…」が削除され、端末リガチャはフォント固有のものが GPU レンダラで結合しなくなる場合がある。ブラウザのパスワード保管庫は OS のセキュアストレージが必須。Chat UI は Experimental を卒業した。
Git Graph タブが加わり、ローカル/リモートのブランチとタグ、各コミットの詳細と変更ファイルを一覧できる。フォルダワークスペースは Source Control を持ち、Chat UI では /btw が本筋を止めずに fork で横質問をし、/fork が直近の応答から分岐する。
スマホは端末側での音声入力（iPhone は iOS 26 以降、Android も対応）と、デスクトップに届かない間の送信キュー、アプリ終了をまたぐ下書き・添付・未保存編集の保持が入った。
エージェント運用では worker が自分の worker を起動でき（既定深さ 4）、コーディネータ終了後も worker が残る。Claude/Codex チャットの Plan モード、使用量上限リセット後の自動継続（任意）、Codex のアカウント履歴連携による入力ラグの修正もある。プラグインはカラーテーマ・独自エディタ・ステータス項目・Ghostty/Kitty 設定の取り込みに対応し、Chrome 互換のパスワードマネージャも加わった。
