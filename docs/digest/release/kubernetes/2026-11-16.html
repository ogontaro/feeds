破壊的変更: Alertmanager の SNS receiver がデフォルトで明示的な認証情報(access key / secret key)を要求するようになり、use_aws_http_client を設定した receiver は拒否される。テナント設定は API 受信時だけでなくストレージからの読み込み時にも検証される。既存テナントは -alertmanager.tenants-exempt-from-config-validation-for-existing-config で除外できる。
