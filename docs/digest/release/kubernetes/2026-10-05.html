Longhorn v1.13.0

破壊的変更: あり。CSI external-provisioner が v6.3.0 になり、Kubernetes v1.34 以上が必須。v1.12.0 以前で作った V2 linked-clone ボリュームは detach か delete しかできない(同じソースから作り直せばデータコピーは不要)。V2 の live upgrade は v1.12.2 からのみ対応。
