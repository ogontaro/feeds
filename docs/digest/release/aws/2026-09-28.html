今週のリリース

terraform-aws-eks v21.25.2 〜 v21.26.0

破壊的変更: なし
EKS モジュールの小規模アップデート3本。v21.26.0 でブロックストレージ用の AmazonEKSBlockStoragePolicy を v2 にオプトインできるようになった（既定は従来のままなので、明示的に有効化しない限り挙動は変わらない）。v21.25.3 は IPv6 の CNI ポリシーに不足していた IAM 権限を追加し、IPv6 クラスタで CNI 関連の権限エラーが出る問題を修正。v21.25.2 はセルフマネージドノードグループで起動テンプレートのネットワーク帯域要件が反映されない問題を修正。
IPv6 + CNI を利用している場合は v21.25.3 以降への更新を推奨。それ以外は通常のパッチ更新として適用できる。
