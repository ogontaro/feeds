mise v2026.11.8（vfox / mise-* クレートも同時更新）

破壊的変更: 明示的な破壊的変更はなし。bootstrap の macOS 設定キーは [bootstrap.settings.macos] へ移動した
bootstrap に実験的な settings プラグインが入り、[bootstrap.settings.<plugin>] で他プログラムの設定を「差分のキーだけ書く」形で管理できるようになった。システム共通のプラグイン置き場（/usr/share/mise/plugins、MISE_SYSTEM_PLUGINS_DIRS）と、/etc/hosts のような管理外ファイルをマーカー付きブロックで編集する [bootstrap.files] の block 指定も追加。mise bootstrap plan がリポジトリとフックを create/update/unchanged で表示する。コマンドラッパーの args/env テンプレートで argv（利用者が渡した引数）が使え、versions_host_exclude で private リポジトリを mise-versions に送らず GitHub 直参照にできる。lockfile・hook-env の性能・tasks・バックエンドの修正も入る。
block は source / content / replace と併用できず解除も手作業なので、dotfiles 側の設定を移すときは順序に注意。宣言化の対象がツールのバージョンから OS・デスクトップ設定へ広がる一歩。

Zellij v0.46.0

破壊的変更: プラグイン開発者向けの破壊的変更あり（CHANGELOG 参照）。musl ビルドにはデスクトップ端末が含まれない

Devbox 0.21.0（0.20.0 から）

破壊的変更: インストーラとランチャーの取得元が Jetify のドメインから GitHub Releases に変わった（0.21.0 以降は新しい install.sh を使う。0.20.0 以前は当面旧エンドポイントで更新が続く）
env / scripts / init_hook の編集が Nix の再計算を起こさなくなり、run/shell のたびの nix print-dev-env が省かれる。binary cache の照会はプロセス単位から 30 日のディスクキャッシュに、プロファイル読み取りは manifest.json 参照に変わり、状態再計算が全体的に速くなった。同一プロジェクトでの並行 devbox run が安全になり（スクリプトをアトミックに書く）、Ctrl-C もコマンド終了まで待つ。リモートプラグインは 15 秒でタイムアウトしてキャッシュに落ちるのでオフラインでも動く。devbox search はバージョンとプラットフォームの表を出す。0.21.0 では停止済み Devbox Cloud の残骸が CLI と VS Code 拡張から消えた。
devbox global を使っているなら、更新手順を curl -fsSL https://raw.githubusercontent.com/jetify-com/devbox/main/install.sh | bash に差し替えておく。性能改善はシェル起動のたびに効くので、体感がはっきり変わる。

破壊的変更: Engine API の仕様原本が OpenAPI 3.2 に移り、バージョン固定の Swagger 2.0 コピーは v1.57 が最後（今後の版は発行されない）。rc では insecure-registries を明示した場合に loopback を勝手に insecure 扱いしなくなった
