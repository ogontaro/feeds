mise v2026.10.25

破壊的変更: mise watch が既定で watchexec に --exit-on-error を渡すようになり、最初に失敗した実行で停止してその終了コードで抜ける（watchexec 2.5.0 以上が必要）。mise tasks add で定義の異なるタスクを --force なしで上書きする操作は 2027.5.0 から警告、2028.5.0 から拒否される予定。
mise tasks set / rm が加わり、add も mise use と同じ --env / --global / --path と、--env-var / --tools / --usage / --confirm を受けるようになった。set は渡したフィールドだけをコメントごと保持して変更し、rm は TOML のテーブルかファイルタスクのスクリプトを消す。3 コマンドとも --json / --dry-run に対応し、複数ファイルが同じタスクを定義しているときは対象ファイルを列挙して止まるので、エディタなしでタスク定義を書き換えられ、エージェントに触らせる範囲を CLI 側で絞りやすい（ランドスケープの「開発環境の宣言化」「コーディングエージェント」）。
mise watch --once は変更を1回待ってタスクを実行し、その終了コードで抜ける。開始時には実行せず（--postpone 相当）、--restart / --clear は拒否、Ctrl-C は 130、待機中の SIGTERM は何も実行せず終了する。スクリプトや CI から「変更があったら1回だけ検証」を素直に書ける。
env_cache_redacted（既定 false）は、redact = true を含む環境を env_cache = true でもキャッシュさせる opt-in。出力時の値はマスクされるが、秘密は activated シェルから起動した全プロセスが継承する鍵で暗号化してディスクに残る。age / sops、cacheable = false のプラグイン結果、redacted な [vars] と default / required は引き続きキャッシュされない。ほかに並行インストール、シンボリックリンクされた設定ディレクトリの lockfile、reshim の遅さ、署名済み macOS アプリバンドルを修正。vfox / mise-util / mise-ui などの内部クレートも同時にリリースされている。

Devbox 0.19.0

破壊的変更: リリースビルドが bash ランチャーを置き換え、バイナリ自身が実行するバージョンを選ぶ（DEVBOX_USE_VERSION、なければ現行版）。devbox version update はインストーラを再実行せず、インストーラ以外で入れた場合は失敗してパッケージマネージャ経由の更新を促す。Nix / Homebrew ビルドは影響を受けず、既存インストールは「New launcher available」が1日1回出て devbox version update で移行する（書き込み不可の場所だけ sudo）。
起動が速くなり、devbox version は約 78ms → 8ms、devbox global shellenv は約 86ms → 16ms。nix のバージョン情報をディスクにキャッシュし、テレメトリはプロジェクトを開き直さず端末 ID をキャッシュして最大30分に1回の送信に、devbox generate direnv --print-envrc は nix チェックとテレメトリを完全に省略する。"on_mismatch": "auto" は作業前にピン留めされたバージョンへ切り替え、ダウンロード済みなら devbox を二重起動せず直接 exec する。同じプロジェクトでの並行実行時に runx バイナリが ENOENT / EEXIST で失敗する問題も修正。devbox global をプロンプトで読んでいるなら shellenv の短縮がそのまま効く。

Node.js 26.13.0 'Lithium' (LTS) / 27.0.0-alpha.0.0.0 / 24.22.2 'Krypton' (LTS)

破壊的変更: 27.0.0-alpha.0.0.0 で V8 が 15.6 になり、--max-old-space-size 未指定時の既定ヒープ上限が物理メモリの半分（256MB〜4GB）に、Buffer / ArrayBuffer のメモリがヒープ上限に算入される。v8.serialize() / structuredClone() / postMessage() の形式も変わり、旧 Node では読めない。OpenSSL 3 以上が必須になり、FIPS プロバイダ同梱ビルドとレガシー OpenSSL 経路は削除された。26.13.0 と 24.22.2 は破壊的変更なし。
