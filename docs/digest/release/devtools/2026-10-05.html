mise v2026.10.2

破壊的変更: 明示的な破壊的変更はありませんが、挙動が変わる点があります。未信頼のプロジェクト設定があってもシェル起動(hook-env)が止まらなくなり(そのファイルだけスキップ)、タイムアウトしたタスクは SIGTERM を捕まえて 0 で終了しても失敗扱いになります。

実験的な spinel: バックエンドが追加されました。Spinel(Matz の Ruby AOT コンパイラ)で GitHub リポジトリの Ruby CLI をネイティブ実行ファイルにビルドするもので、experimental=true と PATH 上の spinel コンパイラが必要、macOS / Linux 限定です。バージョンは git タグから取るため GitHub API を叩きません。将来メンテ負担が大きければ削除される可能性も明記されています。
mise.toml の JSON スキーマが github / gitlab / ubi / http / s3 / cargo / npm / pipx / gem / go / conda などの各バックエンドのツールオプションを型付きで検証・補完するようになり、python / java / rust / dotnet のコアオプションや platforms.<os>-<arch>、[tasks.*.tools] も対象です。エディタが既存設定の誤りを指摘し始めるので、upgrade 後に一度確認しておくと安全です。
Windows では mise daemons start のプリセット(postgres など、redis を除く)が動くようになりました(PostgreSQL の正常停止には pitchfork 2.29.0 以降)。ほかに untrusted 設定でのシェル起動、設定リロード失敗時の SIGABRT とコアダンプ、--no-config / MISE_NO_CONFIG=1 が .miserc.toml を読んでしまう問題、タスクのタイムアウト処理(Windows は Ctrl+C で後始末)などが修正されています。vfox / mise-settings / mise-sigstore / mise-brew-metadata / mise-bootstrap / mise-agent-env / mise-cache-core / mise-interactive-config / mise-util の各リリースはバージョン更新のみです。

herdr v0.9.2〜v0.9.3

破壊的変更: Herdr 独自のペイン画像 API(pane.graphics.info / set / clear / stream)が削除され、unknown_method を返すようになりました。画像表示は端末標準の Kitty graphics を書く方式へ移行し、Herdr がネイティブに描画します。

v0.9.2 ではエージェントが自分の resume コマンドを報告できるようになり、サーバー再起動後に各エージェントのセッションをそのまま開き直せます(組み込み連携は不要)。プレフィックスキーは prefix = ["ctrl+space", "ctrl+s"] のように複数持て、Go To はワークスペースごとにエージェント／端末を状態とパス付きで1行ずつ表示します。ペインをクリックしても余計な Escape を送らなくなり、エージェントの初回タスクが「完了」と誤通知される問題も直っています。
描画・転送も改善しました。ローカル Ghostty へは一時ファイル経由で画像を渡して高速化し、スクロールで画面外に出た画像は保持、保存済みマシンへのスクロールは変更行だけを送信、SSH 接続は圧縮を要求します。新規ペインは TERM_PROGRAM=herdr を設定し、Windows のペインは pwsh を既定に、復元エージェントは 100ms 間隔で1つずつ起動します。イベント購読は取りこぼしを黙って飛ばさず events_lost を返します。
v0.9.3 は hotfix です。ペイン内で Escape を伴うショートカットが再び効くようになり、macOS の Option+←/→ や Option+Backspace、Escape ベースの Shift+Enter が復活しました。Claude Code で Shift+Enter が改行を挿入せず送信してしまう問題が直っており、常用環境では優先して取り込みたい内容です。

Docker Engine (moby) v29.8.2 / v25.0.18

破壊的変更: なし(セキュリティ修正が中心)。

v29.8.2 は多数の脆弱性を修正する重要なセキュリティリリースで、早めの更新を推奨します。CVE-2026-53493(細工した OCI イメージインデックスの深いネスト／広いファンアウトで CPU とメモリを無制限消費)、CVE-2026-92543(悪意ある DNS 応答でレジストリ接続が TLS 証明書検証をスキップし HTTP にフォールバック、認証情報が漏洩・イメージ差し替えの恐れ)、CVE-2026-92542(Swarm ノードの非特権ユーザーが暗号化オーバーレイ網へ偽イーサネットフレームを注入)に加え、BuildKit に CVE-2026-93315〜93326(ビルドキャッシュ汚染、デーモンのクラッシュやメモリ枯渇、ソースポリシー回避など)が多数含まれます。旧系列の v25.0.18 も CVE-2026-17106(tar 展開が抽出先ディレクトリ外へ書き込む)を修正しているため、据え置き環境も更新対象です。
v29.9.0-rc.1 は次期版の RC で、containerd イメージストアのプルで必須レイヤが欠けて push / export 不能になる問題、routed gateway モードで docker ps が公開ポートを出さない問題、暗号化オーバーレイ網の一部トラフィックが平文で送られる可能性、ノード離脱後のオーバーレイピア到達不能などを修正しています。ほかに Go クライアント client/v0.6.1(フック API の追加と WithResponseHook の非推奨化)、api/v1.56.1(OpenAPI / swagger 修正)、内容のない v2.0.0-beta.25 があります。

uv 0.12.20〜0.12.23

Biome CLI v2.5.15

破壊的変更: なし。

nursery ルールが多数追加されました。React のデフォルト props に配列・オブジェクト・関数を禁じる noReactObjectTypeAsDefaultProp、Svelte の旧 export let を禁じて $props() を促す noSvelteExportLet、$app/stores から $app/state への移行を促す useSvelteKitRuneImports、CSS の論理プロパティを強制する useLogicalProperties(direction オプション付き)、曖昧な真偽値チェックを報告する useStrictBooleanExpressions、不要な void を報告する noMeaninglessVoidOperator、Astro の set:html と子コンテンツの併用などを報告する noAstroConflictingSetDirectives です。
