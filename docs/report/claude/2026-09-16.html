Claude Code v2.1.273 リリース — LLMゲートウェイ向けヘッダーとリモートセッションのフォークに対応

LLMゲートウェイ経由でClaude Codeを運用しているなら、x-claude-code-request-classなどのリクエストヘッダー追加（CLAUDE_CODE_GATEWAY_HINT_HEADERS=1で有効化）はログ分析やルーティングに直結する地味だが効く変更。MCPサーバーが切断して自動再接続もあきらめた際に/mcpを案内する通知や、Claudeアプリから始めたリモートセッションをバックグラウンドでフォークできる機能も、日々の運用・並行作業のワークフローに関わる人は要チェック。
