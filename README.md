# feeds

自分用の技術情報収集サイトです。追っている海外サイトの新着を日本語で拾い読みしつつ、Claude が選んだものだけを
日次・週次・月次のレポートで読めます。すべて GitHub Actions が自動で更新し、GitHub Pages で公開しています。

**公開先**: <https://ogontaro.github.io/feeds/>

機能ごとの「なぜあるか」は [FEATURES.md](./FEATURES.md)、設定・実装は [CONTRIBUTING.md](./CONTRIBUTING.md) にあります。

## できること

時刻はすべて日本時間です。目的の違う 2 つのサービスに分かれています。**翻訳フィード**は全部を拾い読みするため、**デイジェスト**は選ばれたものを読むためのものです。

### デイジェスト（Claude が選んで整理する）

| 機能 | 内容 | 更新 |
| --- | --- | --- |
| 日次レポート | 前日の新着と X のタイムラインから、読む価値のある記事を最大 5 本選び、日本語でコメントします。claude / kubernetes / aws の分野ごとに 1 本です | 毎日 07:00 |
| 週次リリース | 使っているツールの 1 週間分のリリースを、破壊的変更を先頭にして整理します。上の 3 分野と devtools（手元の開発ツール）ごとに出ます | 毎週月曜 07:30 |
| 月次トレンド | 前月のレポートと外部の調査・専門家の記事から、業界の潮流（新しい概念が現れて定着していく流れ）をまとめます。分野を横断した 1 本です | 毎月 2 日 07:45 |
| 技術ランドスケープ | 自分の関心領域と、追っている技術の位置づけ（Adopt / Trial / Assess / Hold）をレーダー図で一望するページです。月次トレンドのたびに更新します | 毎月 2 日 |

海外記事には、日本語の概要・原文・Google 翻訳のリンクが必ず付きます。
技術ランドスケープは各レポートの参考資料にもなり、「自分の環境にとってなぜ重要か」をコメントに反映させています。

### 翻訳フィード（全部を日本語で拾い読みする）

海外サイトの新着を、タイトルと概要だけ日本語にしてそのまま流します。選定もコメントもしません。
1 サイトにつき 1 フィードで、日本語のサイトには作りません。6 時間ごとに更新します。

### 購読のしかた

RSS リーダーには OPML でまとめて登録できます（サービスごとに分けてあります）。

- デイジェスト: `opml/digest.opml`
- 翻訳フィード: `opml/translated.opml`

## 運用

ほとんど自動で回ります。やることは次のとおりです。

- **要望は Issue に書く**: 「このサイトを追加して」「このキーワードを関心に入れて」などを書くと、自動で反映されます
- **関心領域を書く**: `landscape.yaml` の `focus` に、分野ごとの関心を自分の言葉で書きます。
  技術ランドスケープのページと、各レポートの選び方に反映されます
- **気になった記事にスターを付ける**（Inoreader）: 読まれなかったフィードの見直しに使われます
- **失敗の修正 PR をレビューする**: ワークフローが失敗すると Issue と修正 PR が自動で作られます。PR は自動ではマージされません
- **棚卸し Issue に答える**（毎月 1 日）: 新しく使い始めたツールがあれば購読リストに足します

購読フィードの見直し（毎週日曜）など、それ以外は自動で動いています。
