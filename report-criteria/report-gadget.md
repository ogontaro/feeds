# ガジェットレポートの選定基準

`report-gadget-input.json`（過去24時間の新着、タイトルと概要は日本語化済み）と `x-recent.json`（X タイムラインの
ポスト。扱いは `x-posts.md` に従う）から、**読者に見てほしいものだけ**を選ぶ。上限は X のポストを含めて
**5 件**、下限は無い。「まあ参考になる」程度のものは載せず、件数を埋めるために選ばない。
記事・ポストとも該当が無ければ「本日の対象記事はありませんでした」とだけ書く。

## 重視する軸

1. **Meta のスマートグラス・VR/MR 関連を最重点**
   - Ray-Ban Meta / Meta Ray-Ban Display / Orion などのグラス新製品・新機能・価格・発売地域（日本展開を含む）
   - Meta Quest の新型・ソフトウェアアップデート・価格改定
   - Reality Labs の戦略・開発者向け施策の変更
   - 該当する記事があれば以下は候補日に必ず1本拾う（他の記事より優先）:
     - 新製品の発表・発売日・価格の確定
     - 日本での発売・対応の発表
2. **上記に次ぐもの** — Apple Vision Pro・Android XR・Samsung 等、XR 業界全体の製品発表と市場動向
3. **読者への効き（従）** — 購入判断に効くか、開発者向けに影響があるか

## 除外するもの

- 求人・宣伝・イベント告知で製品情報としての中身がないもの
- ゲームの個別タイトルの紹介・セール情報
- 同一トピックの重複（最も情報量が多い1本に絞る）
- XR と無関係な Meta 全般のニュース

## 出力フォーマット（`.cache/report-gadget.md` に書く。このファイルだけ）

```
## 今日の N 本

### <日本語タイトル>
<2〜3文の日本語コメント。要約ではなく「なぜ読む価値があるか」を書く。>

[原文を読む](<link>) / [Google 翻訳で全文を読む](https://translate.google.com/translate?sl=auto&tl=ja&u=<URLエンコードした link>)
```

日本語の記事はリンク行を `[記事を読む](<link>)` だけにする（原文・Google 翻訳の2リンクは海外記事のみ）。

## 深掘りオプション

入力の中に同一トピックについて複数ソースから記事が集まっている日は、通常の複数選定に代えて、
そのトピック1本を深掘りする形式を選んでよい（広く浅くより、たまには1本をじっくり読みたい）。
その場合は上記の代わりに以下の形式で書く。

```
## 今日の深掘り: <トピック名>

<5〜8文の日本語コメント。複数ソースの内容を統合し、背景・論点・購入判断への影響を掘り下げる。>

- [ソース1を読む](<link1>)
- [ソース2を読む](<link2>)
```
