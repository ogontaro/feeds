# ガジェットレポートの選定基準

`report-gadget-input.json`（過去24時間の新着、タイトルと概要は日本語化済み）と `x-recent.json`（X タイムラインの
ポスト。扱いは `x-posts.md` に従う）から、**XR 業界で大きく注目される更新だけ**を選ぶ。上限は X のポストを含めて
**3 件**、下限は無く、0 件の日が普通。Meta のグラス・Quest は記事数が多いが、多いことは選ぶ理由にならない。
記事・ポストとも該当が無ければ「本日の対象記事はありませんでした」とだけ書く。

## 載せるもの

- 新製品の正式発表・発売日・価格の確定（Meta のグラス・Quest、Apple Vision Pro、Android XR 端末など）
- 日本での発売・対応の正式発表
- 製品の使い方が変わる大型アップデート（新しい入力方式・主要機能の追加、OS のメジャー版）
- Reality Labs の事業方針の転換（製品ラインの終了・統合、開発者プラットフォームの大きな変更）

## 除外するもの

- 小さな機能追加・定例のソフトウェアアップデート・不具合修正
- 噂・リーク・特許・アナリスト予測（正式発表になってから拾う）
- レビュー・使い方・比較・コラム・インタビュー
- セール・値引き・バンドル情報、ゲームやアプリの個別タイトル紹介
- 求人・宣伝・イベント告知で製品情報としての中身がないもの
- 同一トピックの重複（最も情報量が多い1本に絞る）
- XR と無関係な Meta 全般のニュース

## 出力フォーマット（`.cache/report-gadget.md` に書く。このファイルだけ）

```
## 今日の N 本

### <日本語タイトル>
<2〜3文の日本語コメント。要約ではなく「なぜ読む価値があるか」を書く。>

[原文を読む](<link>) / [Google 翻訳で全文を読む](https://translate.google.com/translate?sl=auto&tl=ja&u=<URLエンコードした link>)
```

日本語の記事はリンク行を `[記事を読む](<link>)` だけにする（原文・Google 翻訳の2リンクは海外記事のみ）。

## 深掘りオプション

「載せるもの」に当たるトピックについて複数ソースから記事が集まっている日は、通常の複数選定に代えて、
そのトピック1本を深掘りする形式を選んでよい（広く浅くより、たまには1本をじっくり読みたい）。
その場合は上記の代わりに以下の形式で書く。

```
## 今日の深掘り: <トピック名>

<5〜8文の日本語コメント。複数ソースの内容を統合し、背景・論点・購入判断への影響を掘り下げる。>

- [ソース1を読む](<link1>)
- [ソース2を読む](<link2>)
```
