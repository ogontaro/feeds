# Claude レポートの選定基準

`report-claude-input.json`（過去24時間の新着、タイトルと概要は日本語化済み）から、
重要なものを **5〜10 件** 選ぶ。0 件なら「本日の対象記事はありませんでした」とだけ書く。

**新しいコーディングエージェント系ツール・MCPサーバーの紹介記事**（opencode のような
「何の課題を解くツールか」が分かるもの。Show HN 的な新規プロジェクト発表も含む。月額 10 ドル
前後のサブスク型サービスの提供開始・料金変更も同様）は、他の記事との枠の取り合いで
落とさない。入力に該当するものがあれば **必ず 1 件以上**選ぶ（5〜10 件の内数でよい）。

## 重視する軸

1. **関心領域との一致（主）**
   - Claude / Anthropic のモデル更新・新機能
   - Claude Code / Claude API の使い方・ベストプラクティス・落とし穴
   - Claude を使った開発の実装事例、エージェント設計
   - AI 全般（AI 支援開発、AIエディタ、SRE/プラットフォームでの AI 活用等）の実務に効く話題
   - 新しいコーディングエージェント系ツール・MCP サーバーの紹介（上記の必須採用ルール参照）
2. **実務への効き（従）** — 設計判断や日々の開発に効くか、広く参照されそうか

## 除外するもの

- 求人・宣伝・イベント告知でエンジニアリング的な中身がないもの
- 同一トピックの重複（最も情報量が多い1本に絞る）
- AI 一般ニュースは実務に効くものだけ採用する（新モデル発表の速報や噂話だけのものは除外）
- 「CCログ超訳」の 1 変更 = 1 エントリの細かい changelog 項目は、重要なものだけ 1〜2 件に集約する

## 出力フォーマット（`.cache/report-claude.md` に書く。このファイルだけ）

```
## 今日の N 本

### <日本語タイトル>
<2〜3文の日本語コメント。要約ではなく「なぜ読む価値があるか」を書く。>
[原文を読む](<link>) / [Google 翻訳で全文を読む](https://translate.google.com/translate?sl=auto&tl=ja&u=<URLエンコードした link>)
```

## 深掘りオプション

入力の中に同一トピックについて複数ソースから記事が集まっている日は、通常の複数選定に代えて、
そのトピック1本を深掘りする形式を選んでよい（広く浅くより、たまには1本をじっくり読みたい）。
その場合は上記の代わりに以下の形式で書く。

```
## 今日の深掘り: <トピック名>

<5〜8文の日本語コメント。複数ソースの内容を統合し、背景・論点・実務への影響を掘り下げる。>

- [ソース1を読む](<link1>)
- [ソース2を読む](<link2>)
```
