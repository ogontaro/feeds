# X タイムラインのポストの扱い（各ドメイン共通）

`x-recent.json` は X ホームタイムラインの過去24時間のポスト（`text` 本文、`link` ポスト URL、
`author` 投稿者ハンドル、`links` 本文中の外部 URL、`published`）。大半はエンジニアリングと無関係な
ポストなので、**このドメインの選定基準（重視する軸）に合うものだけ**を記事と同じ土俵で選ぶ。
合わないポストは、他ドメイン向けの内容でも技術的に有益でも載せない（他ドメインのレポートが拾う）。

このレポートは誰でも読める公開ページになる。迷ったら載せない。

## 載せ方

- X 用の見出し・グループは作らない。ドメインの選定基準にある `##` グループに記事と混ぜて入れる
- 選定件数の上限には X のポストも含める
- 同じ話題のポスト（同じリリース・同じ記事・同じ障害への言及）は 1 項目にまとめる。
  フィードの記事と同じ話題なら記事の項目にまとめ、ポストはリンクを 1 行足すだけにする
- 要約は入力に書かれている事実だけで書く。推測で補わない
- 投稿者は URL 上のハンドル（`author`）でだけ示す。表示名や人物評は書かない

## 必ず除外するもの

- 技術と無関係なポスト（ゲーム、アイドル・芸能、食事、スポーツ、政治・時事、日常の近況など）
- 個人の私生活・人間関係・私的なやり取り（リプライの応酬など）。技術的な中身があっても、
  特定の個人の事情を読み取れる形では書かない
- 宣伝・求人・イベント告知だけで技術的な中身がないもの、感想だけで情報がないもの

## 項目の形式

```
### <日本語の見出し>
<2〜3文の日本語コメント。何が起きた/分かったか、なぜ見る価値があるかを書く。>

- [<author> のポスト](<link>)
- [リンク先を読む](<links の URL>)
```

- ポストが日本語以外なら、ポストの行を
  `[<author> のポスト（原文）](<link>) / [Google 翻訳で読む](https://translate.google.com/translate?sl=auto&tl=ja&u=<URLエンコードした link>)` にする
- 外部リンクが海外（日本語以外）のページなら、その行を
  `[原文を読む](<URL>) / [Google 翻訳で全文を読む](https://translate.google.com/translate?sl=auto&tl=ja&u=<URLエンコードした URL>)` にする
- 外部リンクが無いポストは「リンク先を読む」の行を出さない
